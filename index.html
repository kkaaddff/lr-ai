无损流程

原片永远是原片

所有调整只是一份参数 JSON,存进照片所在文件夹的隐藏目录 .lrai/,改动自动保存;整张图只在导出的那一刻才渲染。删掉 .lrai/,一切如初。

  • 参数、AI 对话、历史全在本地
  • 导出 JPEG / HEIC / PNG / TIFF,可保留 EXIF(默认去 GPS)
  • 相机水印:白边 / 黑边信息条,内容逐项勾选

直读 RAW

系统解码器,不用装任何库

CR3 / CR2 / NEF / ARW / DNG 相机 RAW,加上 JPEG / PNG / HEIC / WebP / TIFF,全部走系统解码器;EXIF 方向自动应用,完整元数据 ⌘I 一屏看完。

  • 合焦点显示:读相机记录的对焦框,Canon 眼部追踪实测落框在眼 / 脸
  • 没有对焦数据时,按清晰度估计最清晰区域(虚线框)
  • lrai-check 命令行工具,先验证你的片子再说话

历史树

撤销之后再改,长出新的枝

每张照片一棵历史树,每次改动是一个节点;800 毫秒内的连续拖动合并成一步,拖回原值自动撤掉。回到任何一步继续调,旧分支不会丢 —— 大胆试,不迷路。

  • ⌘Z / ⇧⌘Z 撤销重做,head 在树上移动
  • AI 的每次改动也只是历史里的一步

批处理

选一批,一个风格

多选照片逐张处理或统一风格;同步设置、匹配曝光与白平衡,把一组片子先「拉平」再统一调。可以整批撤销,也可以逐张复查微调。

  • 匹配曝光 / 白平衡,组内对齐
  • 整批撤销,逐张复查

你会关心的事

它和 Lightroom 是什么关系?

没有任何依赖关系。LR·AI 对齐的是 Lightroom「修改照片」模块的参数空间与交互习惯(约 60 个滑杆、色调曲线、HSL、预设),预设文件 .xmp 可以互导;渲染引擎完全自研 —— AppKit + ImageIO + Accelerate,零第三方依赖,不需要安装 Lightroom 或 Adobe 的任何东西。

AI 助手会上传我的照片吗?

不会发原图。App 只把 ≤900px 的降采样代理图(原图 / 编辑后 / 参考图)与当前参数写进照片文件夹下的本地临时目录,交给本机的 claude CLI 处理;账号、密钥都是你自己的,App 不内置任何接入。整个过程零网络请求由 App 发起。

会改动我的原片吗?

不会。所有调整只存成参数 JSON,放在照片所在文件夹的隐藏目录 .lrai/ 里,改动自动保存;整张图只在导出时渲染,并且导出是另存新文件。删掉 .lrai/,一切如初。

支持我的相机 / 格式吗?

相机 RAW 走系统解码器,实测覆盖 CR3 / CR2 / NEF / ARW / DNG 等主流格式,JPEG / PNG / HEIC / WebP / TIFF 也都支持。不确定的话,仓库里的 lrai-check 命令行工具可以直接打印一张图的解码信息与耗时,先验再装。

AI 改坏了怎么办?

一次 agent 改动就是历史树里的一步:面板上直接「还原」,或者 ⌘Z;想再试一次就「重新应用」。它拧的滑杆和你拧的滑杆,在历史里地位完全一样。
